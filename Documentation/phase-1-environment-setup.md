# Phase 1 - Environment Setup

## Objective

The objective of this phase is to prepare the virtual environment required for the deployment of a Wazuh SIEM/XDR laboratory.

The goal is to create a controlled cybersecurity lab environment where security events can be collected, monitored, analyzed and investigated.

## Lab Architecture

The initial laboratory environment will consist of:

- Host machine: Windows 11
- Hypervisor: VMware Workstation Pro
- Server operating system: Ubuntu Server 24.04 LTS
- Security Platform: Wazuh SIEM/XDR

## Environment Preparation

The following components will be installed and configured:

### Virtualization Platform

Software:
- VMware Workstation Pro

Purpose:
- Create and manage virtual machines required for the cybersecurity laboratory.
- Provide an isolated environment for security monitoring and testing activities.

### Ubuntu Server

Operating System:
- Ubuntu Server 24.04 LTS

Purpose:
- Host the Wazuh Manager components.
- Collect and analyze security events generated by monitored endpoints.

## Network Design

The laboratory network will use a NAT configuration to provide internet access to the virtual machine while maintaining isolation from the host environment.

Network Purpose:

- Allow operating system updates and software installation.
- Enable communication between the Wazuh Manager and monitored endpoints.
- Maintain a controlled and secure testing environment.
