# Wazuh SIEM/XDR Home Lab

## Overview

This project documents the deployment of a complete Wazuh SIEM/XDR home laboratory using Ubuntu Server running on VMware Workstation.

The purpose of this lab is to gain practical cybersecurity experience by building, configuring, monitoring and documenting a Security Information and Event Management (SIEM) environment.

---

## Objectives

This laboratory focuses on developing hands-on skills in:

- SIEM deployment
- Linux administration
- Log collection
- Security monitoring
- Threat detection
- Security event investigation
- Endpoint monitoring
- Git and GitHub documentation

---

## Technologies

- Wazuh SIEM/XDR
