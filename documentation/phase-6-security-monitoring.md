# Phase 6 - Security Monitoring

## Overview

In this phase, Wazuh SIEM was used to monitor a connected Windows 11 endpoint and validate security event collection, detection, and basic alert investigation.

The objective was to confirm that the endpoint was successfully communicating with the Wazuh Manager, generate controlled security activity, review collected events, and perform a basic analysis of detected activity.

---

## Objectives

The main objectives of this phase were:

- Verify endpoint communication with Wazuh.
- Confirm security event ingestion from Windows 11.
- Generate controlled user activity for testing.
- Review detected security events.
- Perform a basic alert investigation.

---

# Step 1 - Agent Status Verification

## Description

The first step was validating that the Windows 11 endpoint remained connected to the Wazuh Manager.

The agent status was checked from the Wazuh Dashboard under:

```
Agents → lab-win11
```

## Validation Results

The endpoint was successfully connected and actively communicating with Wazuh.

Evidence collected:

- Agent Name: `lab-win11`
- Status: Active
- Operating System: Windows 11

# Step 3 - Controlled Event Generation

## Description

Controlled activity was generated on the Windows 11 endpoint to validate event detection.

The following commands were executed using PowerShell:

```powershell
whoami
hostname
ipconfig
```

These commands generated endpoint activity that could be monitored through Wazuh.

---

# Step 4 - Authentication Event Generation

## Description

A controlled authentication event was generated by locking and unlocking the Windows session.

The following action was performed:

```
Windows + L
```

After unlocking the session, Wazuh was monitored for new authentication-related events.

This generated a successful Windows logon event.

---

# Phase 6 Summary

During this phase, Wazuh successfully monitored the Windows 11 endpoint and collected security-related events.

The investigation validated:

- Successful agent communication.
- Security event ingestion.
- Endpoint activity monitoring.
- Authentication event detection.

This phase demonstrates the fundamental workflow of a Security Operations Center (SOC):

1. Monitor endpoint activity.
2. Detect security events.
3. Review alert details.
4. Analyze the context.
5. Determine whether activity is normal or suspicious.
