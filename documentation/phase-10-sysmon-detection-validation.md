# Phase 10 – Sysmon Detection Validation

## Objective

The objective of this phase was to integrate Sysmon telemetry into the Wazuh SIEM environment and validate endpoint detection capabilities through Windows process monitoring.

This phase focused on improving endpoint visibility by collecting detailed process execution data, analyzing PowerShell activity, and validating security alerts generated by Wazuh.

---

# Implementation

Implemented:

* Sysmon installation on the Windows 11 endpoint.
* Sysmon Operational event collection.
* Wazuh Agent integration with Sysmon logs.
* Forwarding Sysmon telemetry to the Wazuh Manager.
* Validation of process creation monitoring.
* Investigation of PowerShell-based activity.

---

# Sysmon Integration

Sysmon was installed on the Windows 11 endpoint to provide enhanced telemetry for security monitoring.

The monitored Windows Event Channel:

```
Microsoft-Windows-Sysmon/Operational
```

The Wazuh Agent was configured to collect Sysmon events and forward them to the Wazuh Manager for analysis.

Validation performed:

* Confirmed Sysmon service execution.
* Confirmed Sysmon event generation.
* Confirmed Wazuh Agent collection.
* Confirmed events visible in Wazuh Dashboard.

---

# Detection Scenario

A controlled PowerShell activity was executed on the Windows endpoint to generate Sysmon telemetry.

Command executed:

```powershell
Invoke-WebRequest https://example.com -UseBasicParsing
```

This activity generated a Sysmon Process Creation event.

---

# Sysmon Event Analysis

Detected Sysmon Event:

```
Event ID 1 - Process Creation
```

Collected telemetry included:

* Process name.
* Process ID.
* Parent process.
* Command line arguments.
* User context.
* Integrity level.
* File hashes.
* Process execution timeline.

Example detected process:

```
Image:
C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe
```

Command line:

```
Invoke-WebRequest https://example.com -UseBasicParsing
```

User:

```
Adrian\Adrian
```

---

# Wazuh Detection

The generated telemetry was successfully analyzed by Wazuh and produced a security alert.

Alert information:

```
Rule ID:
92027
```

Rule description:

```
Powershell process spawned powershell instance
```

Severity:

```
Level 4
```

Detection group:

```
sysmon
sysmon_eid1_detections
windows
```

# MITRE ATT&CK Mapping

The detected activity was mapped to the MITRE ATT&CK framework.

Technique:

```
T1059.001 - PowerShell
```

Tactic:

```
Execution
```

This technique represents the use of PowerShell for command execution, commonly observed during legitimate administration tasks as well as attacker activity.
